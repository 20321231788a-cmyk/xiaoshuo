# ArcWriter 1.2.0

发布日期：2026-08-02

## 发布定位

这是 ArcWriter 的正式 GitHub Release，但只面向小规模使用。本版本按明确授权跳过 RC，不代表已经完成商业化签名、封闭数据集、长时间 soak、固定设备性能或盲评等正式商业发布门槛。

安装包可能未签名，Windows 可能显示 SmartScreen 提示。使用前请备份小说项目目录；遇到问题可用 `--safe-agent` 回退受控 Agent 能力。

## 本版本重点

- 故事大纲支持中间区域就地编辑、保存、取消和删除情节点。
- 新建项目默认进入 AI 助手；助手内最近选择的模型同时成为全局默认模型。
- 思考模式支持独立开关、思考等级和思考内容流式展示。
- AI 上下文继续读取大纲、设定、风格、题材、近期正文和蒸馏原文证据。
- 生成内容统一支持预览、确认、丢弃、真实保存回执和失败保留。
- 正文侧栏改为独立迷你 AI 对话，新增“扩写当前段落”。
- 拆书流程统一为“导入待拆 → 原书拆解 → 正式入库”；蒸馏注入可追溯原文证据，融梗和蒸馏确认后才写入目标资料。
