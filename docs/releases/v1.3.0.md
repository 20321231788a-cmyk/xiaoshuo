# ArcWriter 1.3.0

发布日期：2026-08-04

## 本版本重点

- 修复桌面端 AI 助手真实流式输出，Model Gateway 现在保留模型思考和回答两个通道；开启思考模式后可实时查看思考内容。
- 拆书、融梗、蒸馏、续写和扩写均使用独立任务会话，不会污染普通 AI 助手对话上下文。
- AI 对故事大纲、风格、题材和设定资料的确认保存改为写入结构化主数据，并在提交后立即刷新对应页面。
- 故事大纲支持分卷的新建、编辑、章节归属、排序和删除；拆书与批量生成增加任务状态、进度、失败原因及恢复操作。
- 设置页移除备用 API 线路，新增可选的轻量任务模型。该模型从当前主路线 API 的模型列表选择，并接管原备用线路的摘要、一致性检查和辅助生成用途；未选择时继续使用主模型。
