# ArcWriter 1.3.1

发布日期：2026-08-04

## 本版本重点

- AI 助手在存在候选项目资料时显示可操作的确认面板，支持选择资料、直接发送和取消；不再出现只有“待确认写入”文字而无法确认的状态。
- 新建项目在创建时登记 manifest UUID 与物理目录身份；用户显式新建或重新打开项目可恢复已被重新创建目录占用的路径记录，后台写入仍会拒绝未确认的身份冲突。
- 空白项目模板不再被当作有效参考资料；项目资料草稿加载失败会显示真实不可用原因，不再误导为可确认写入。
- 会话标题栏直接提供改名、会话摘要与删除入口，删除前二次确认；不再把这些操作隐藏在三点菜单中。

## 发布与验证

- 发布工作流从 `v1.3.1` 带注释标签检出源码，执行 `npm run acceptance:preview`，再构建 Windows 安装包。
- 发布附件仅包含 `ArcWriter-Setup-1.3.1.exe`、对应 `.blockmap` 与 `latest.yml`。

## 发布定位

这是已授权的免费、小范围正式发布：GitHub Release 为非预发布且可标记为 Latest，但仅适用于小规模用户使用。
