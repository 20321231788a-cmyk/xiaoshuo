# ArcWriter 1.1.0

ArcWriter 1.1.0 集中交付小说创作工作台、AI 助手与项目数据管理改造。

## 主要更新

- 项目首页整合最近项目与网站同步，支持三个云端小说槽位、手动/自动同步、明确替换和流量额度提示。
- 云同步仅处理大纲、细纲、正文、风格、题材等核心文件；单本上限 30 MB，不上传密钥、会话、日志、任务和内部记录。
- AI 助手支持会话级模型选择、真实思考等级、Codex 式消息布局和简洁输入栏。
- 新增小说封面生成，支持文生图、图生图、题材库默认风格、600×800 成品和历史版本。
- 拆书工作台增加单书蒸馏与多书融梗入口。
- 编辑器增加中文标点栏与实时打字速度，自动写作能力集中到“创作工具 → 写作与审阅”。
- 新增覆盖全部生产页面、设置二级页和技能三级页的完整教程，按 `F1` 可随时打开。
- 完成全量 UI 收口、交互补齐、设置响应式修复和用户可见状态统一。

## 数据安全

- AI 写入继续经过“生成结果 → 差异预览 → 用户确认 → 版本记录 → 写入”。
- 云端恢复前创建本地备份，只处理同步白名单内的核心文件，不删除其他本地资料。
- 生产界面不显示日志、Trace、终端、哈希、IPC、令牌或内部提示词。

## 安装说明

- Windows 安装包：`ArcWriter-Setup-1.1.0.exe`
- 升级或恢复云端数据前，建议先备份当前小说项目。
- 未签名的 Preview 安装包可能触发 Windows SmartScreen；正式发布附件以 GitHub Release 页面标注为准。
